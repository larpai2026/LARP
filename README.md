# LARP — чистая стартовая версия

## Windows 10
1. Распакуй архив в отдельную папку, не поверх старого проекта.
2. Скопируй `.env.example` в `.env` и открой `.env` в Блокноте.
3. Заполни `ADMIN_EMAIL` и `ADMIN_PASSWORD` собственными значениями. Не отправляй `.env` никому.
4. Для отправки подтверждений почты заполни SMTP-параметры. Для Mail.ru используй пароль приложения, не обычный пароль.
5. В адресной строке Проводника в папке проекта введи `cmd` и нажми Enter.
6. Выполняй по очереди:

```bat
py -m venv .venv
.venv\Scripts\python -m pip install --upgrade pip
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python app.py
```

7. Открой `http://127.0.0.1:5000`. После входа админ-панель: `http://127.0.0.1:5000/admin`.

## Подключение ИИ
Добавь ключ OpenAI API в `OPENAI_API_KEY` внутри `.env`, сохрани и перезапусти приложение. Использование API может быть платным.

## Важно
Это локальный прототип. Вход Google/Apple, реальные платежи и полноценный анализ PDF/DOCX пока не подключены. Не выставляй встроенный Flask-сервер в интернет; для публичного сервиса нужны HTTPS, production-сервер, защита от перебора паролей и аудит безопасности.
